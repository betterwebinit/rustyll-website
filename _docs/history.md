The [Rustyll releases page](https://github.com/betterwebinit/rustyll/releases) is the source of published versions and release notes. The current release recorded for this website is **v{{ site.version }}**; check the release page for newer versions before installing or upgrading.

## Upgrade with context

1. Read the notes for the version you plan to use.
2. Test the new version against a copy of your site.
3. Review your templates, configuration and plugins before deployment.

For older release details, use the [repository tags](https://github.com/betterwebinit/rustyll/tags) and their linked changes. Historical claims that lacked a matching published release were removed from this page.
